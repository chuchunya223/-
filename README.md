# Эмодзи: от 12×12 пикселей до анимации

Учебный сайт по компьютерной графике об истории эмодзи. Один файл `index.html`, без сборки и зависимостей: все картинки нарисованы кодом (SVG, canvas, CSS), снаружи грузятся только шрифты Google Fonts.

Сайт: https://chuchunya223.github.io/-/

## Посмотреть локально

Открыть `index.html` в браузере.

## Включить GitHub Pages (один раз)

1. В репозитории открыть **Settings** → в меню слева **Pages**.
2. В блоке **Build and deployment**: **Source** → `Deploy from a branch`.
3. **Branch** → `main`, папка `/ (root)` → **Save**.
4. Подождать минуту-две и обновить страницу: сверху появится ссылка на сайт. Ход публикации видно во вкладке **Actions**.

Дальше сайт обновляется сам после каждого изменения в ветке `main`.

## Файлы

- `index.html` - весь сайт
- `favicon.svg` - значок вкладки
- `.nojekyll` - говорит GitHub Pages отдавать файлы как есть, без Jekyll
